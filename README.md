# เช็กสัญญา

เว็บคัดกรองสัญญาเบื้องต้น ผู้ใช้วางข้อความสัญญา แล้วระบบจะไฮไลต์จุดที่ควรระวัง

## โครงสร้างไฟล์

```
project/
├── index.html    โครงหน้าเว็บ (ข้อความ, ปุ่ม, id ของแต่ละส่วน)
├── style.css     หน้าตาและสี
├── rules.js      กฎการตรวจ (คำสำคัญ, ระดับความเสี่ยง, คำแนะนำ)
├── script.js     การทำงานของปุ่มและการแสดงผล
└── README.md     เอกสารนี้
```

**หมายเหตุ:** ไฟล์ที่ได้รับมาชื่อ `style_css.txt` และ `index_html.txt` ให้เปลี่ยนชื่อเป็น `style.css` และ `index.html` ก่อนใช้งาน

## ต้องแก้ไฟล์ไหน

| ต้องการ | แก้ไฟล์ |
|---|---|
| เพิ่มหรือแก้คำสำคัญ / หมวดที่ตรวจ | `rules.js` |
| เปลี่ยนข้อความที่แสดง หรือระยะตัวอย่างข้อความ | `script.js` (ส่วน `CONFIG`) |
| เปลี่ยนสี ขนาด หรือหน้าตา | `style.css` |
| เปลี่ยนข้อความหน้าเว็บ หรือ id ของปุ่ม | `index.html` |

## เพิ่มคำสำคัญใน rules.js

แต่ละหมวดมีรูปแบบนี้

```js
{level:'high', label:'ชื่อหมวด', keys:['คำที่ 1','คำที่ 2'], tip:'คำแนะนำให้ผู้ใช้'}
```

- `level` ใช้ `'high'` (ควรระวังมาก), `'mid'` (ควรพิจารณา) หรือ `'low'` (ควรสังเกต)
- `keys` คือคำที่ระบบจะค้นหา ใส่ได้หลายคำ
- ระบบค้นหาแบบตรงตัว ดังนั้นคำสั้นอาจเจอในคำอื่นได้ เช่น "ยกเลิก" อาจเจอในบริบททั่วไป ควรเลือกวลีที่เจาะจง

## ปัญหาที่พบบ่อยและวิธีแก้

| อาการ | สาเหตุที่เป็นไปได้ | วิธีตรวจ / แก้ |
|---|---|---|
| กดตรวจแล้วไม่มีอะไรเกิดขึ้น | `script.js` หรือ `rules.js` โหลดไม่ได้ | เปิด console ดูข้อความ error. ตรวจชื่อไฟล์และลำดับ `<script>` ใน `index.html` (rules.js ต้องมาก่อน script.js) |
| ขึ้นข้อความ "เกิดข้อผิดพลาดระหว่างตรวจสัญญา" | โค้ดใน `rules.js` มีรูปแบบผิด เช่น ลืมคอมมาหรือวงเล็บ | ดู error ใน console ตำแหน่งที่ระบุจะบอกบรรทัดที่ผิด |
| ปุ่มตรวจแล้วผลไม่เลื่อนขึ้นมา | ไม่มี `class="card"` ที่ครอบ `#result` | ตรวจว่า `<div id="result">` อยู่ใน `<section class="card">` |
| ปุ่มไม่ทำงานเลย | id ใน `index.html` ไม่ตรงกับใน `script.js` | ดู console จะมีข้อความ "ไม่พบ element" บอกชื่อที่หาไม่เจอ |
| ผลตรวจมีหมวดที่ไม่เกี่ยวข้อง | คำในหมวดสั้นหรือกว้างเกินไป | แก้คำใน `keys` ของหมวดนั้นใน `rules.js` |
| หน้าเว็บไม่เปลี่ยนหลังแก้ไฟล์ | เบราว์เซอร์เก็บแคชไฟล์เดิมไว้ | รีเฟรชแบบบังคับ หรือเพิ่ม `?v=2` ท้ายชื่อไฟล์ใน `index.html` เช่น `script.js?v=2` |
| ตรวจบนมือถือแล้วสีหรือฟอนต์ไม่ตรง | ฟอนต์ Sarabun โหลดไม่สำเร็จ | ตรวจการเชื่อมต่อ หรือดูที่ลิงก์ Google Fonts ใน `index.html` |

### วิธีเปิด console บน iPhone

ถ้าทดสอบบน iPhone ต้องเชื่อมต่อกับคอมพิวเตอร์ แล้วใช้ Safari บนคอมพิวเตอร์ เมนู Develop > ชื่อ iPhone > หน้าเว็บ จะเห็น console ที่แสดงข้อความ error

## การทดสอบก่อนปล่อยใช้งาน

1. วางสัญญาที่มีคำสำคัญครบทุกหมวด และตรวจว่าทุกหมวดแสดงผล
2. วางข้อความที่ไม่มีคำสำคัญ และตรวจว่าขึ้นข้อความ "ไม่พบคำสำคัญ"
3. กดตรวจโดยไม่วางข้อความ และตรวจว่าขึ้นข้อความ "กรุณาวางข้อความสัญญาก่อน"
4. วางข้อความแล้วกดล้าง และตรวจว่ามีหน้าต่างยืนยันขึ้นมา
5. ทดสอบบนมือถือจริงอย่างน้อยหนึ่งเครื่อง
